* Memory Allocation and Deallocation happens Automatically in Golang.

new()
--------------
* Allocate the momery but no INIT
* You will get a memory address
* zeroed storage

make()
--------------
* Allcate memory and INIT
* You will get a memory address
* non-zeroed storage

Memory management
------------------
* Garbage Collections(GC) happens automatically
* Out of Scope or nil.
